Model Context Protocol (MCP) — открытый протокол, который стандартизирует, как AI-приложения (ассистенты в IDE, чат-боты, агенты) подключаются к внешним инструментам и данным. Его часто сравнивают с USB-C: один разъём вместо зоопарка проприетарных кабелей.

## Проблема N×M

До MCP каждое AI-приложение интегрировалось с каждым сервисом по-своему:

```text
          GitHub   Jira   Postgres   Figma   Ваш API
Claude      ✎       ✎       ✎         ✎        ✎
IDE A       ✎       ✎       ✎         ✎        ✎
IDE B       ✎       ✎       ✎         ✎        ✎
Агент X     ✎       ✎       ✎         ✎        ✎
            N клиентов × M сервисов = N×M интеграций
```

С MCP сервис один раз реализует **MCP-сервер**, а каждое AI-приложение один раз реализует **MCP-клиент** — и они совместимы друг с другом: N + M вместо N × M.

## Что даёт MCP модели

Языковая модель сама по себе умеет только генерировать текст по контексту. MCP позволяет приложению, в котором работает модель:

- **дать модели инструменты** (tools) — функции, которые она может попросить вызвать: «создать задачу в трекере», «выполнить SQL-запрос», «запустить тесты»;
- **дать доступ к данным** (resources) — файлы, документы, схемы БД, записи, которые можно добавить в контекст;
- **дать готовые сценарии** (prompts) — шаблоны запросов, которые пользователь выбирает в интерфейсе.

```text
Пользователь: «Почему падает сборка в main?»
  → модель решает вызвать tool «get_ci_logs» (MCP-сервер CI)
  → получает логи, видит ошибку компиляции
  → вызывает tool «read_file» (MCP-сервер файловой системы)
  → предлагает исправление
```

## История и экосистема

- Ноябрь 2024 — Anthropic публикует MCP как открытый стандарт.
- 2025 — протокол поддерживают основные AI-клиенты и IDE (Claude, ChatGPT, VS Code/Copilot, Cursor, JetBrains и другие), появляются тысячи серверов; протокол передан под открытое управление (Linux Foundation, Agentic AI Foundation).
- Ревизии спецификации: 2024-11-05, 2025-03-26 (Streamable HTTP, OAuth), 2025-06-18 (структурированный вывод, elicitation), 2025-11-25 и **2026-07-28** — крупнейшая ревизия: протокол стал **stateless** (без сессий и handshake `initialize`).
- Официальные SDK: TypeScript, Python, Java, Kotlin, C#, Go, Rust и др. TypeScript SDK v2 разделён на пакеты `@modelcontextprotocol/server` и `@modelcontextprotocol/client`.

## Где MCP встречается фронтенд-разработчику

| Сценарий | Пример |
| --- | --- |
| AI-ассистент в IDE знает ваш фреймворк | **Angular CLI MCP-сервер** (`ng mcp`): документация, best practices, запуск сборки и тестов, помощь в миграции на zoneless |
| Доступ к дизайну | Figma MCP: ассистент читает макет и генерирует компоненты |
| Работа с задачами и кодом | GitHub, Jira, Linear MCP-серверы |
| Браузер | Playwright / Chrome DevTools MCP: ассистент открывает страницу, смотрит консоль, делает скриншоты |
| Ваш продукт как инструмент для агентов | свой MCP-сервер поверх API продукта |
| Сайт как инструмент для агента в браузере | WebMCP — предложение браузерного API, позволяющего странице объявлять инструменты для агента (в Angular есть экспериментальная интеграция с Signal Forms) |

## MCP — не замена API

MCP-сервер обычно — тонкий адаптер над существующим API: описывает операции так, чтобы модель понимала, когда и как их вызывать, и выполняет их. Хороший MCP-сервер:

- даёт инструменты под **задачи пользователя**, а не зеркалит каждый REST-эндпоинт;
- пишет понятные описания (их читает модель);
- возвращает компактные, структурированные результаты;
- соблюдает права доступа пользователя.

> [!WARNING]
> Подключая MCP-сервер, вы даёте модели возможность действовать от вашего имени. Сторонние серверы — это код с доступом к вашим данным, а данные, которые модель читает через инструменты, могут содержать prompt injection. См. [Безопасность MCP](/tracks/ai-mcp/mcp-security).

> [!INTERVIEW]
> «Что такое MCP и зачем он нужен?» — Открытый протокол для подключения AI-приложений к внешним инструментам и данным. Сервер описывает tools (действия), resources (данные) и prompts (шаблоны), клиент внутри AI-приложения их обнаруживает и предоставляет модели. Это решает проблему N×M интеграций: сервис реализует MCP один раз и работает со всеми совместимыми ассистентами и IDE.

## Коротко

- MCP стандартизирует подключение AI-приложений к инструментам и данным.
- N×M интеграций превращаются в N+M.
- Сервер даёт tools, resources и prompts.
- Ревизия 2026-07-28 сделала протокол stateless.
- Для фронтендера: Angular CLI MCP, Figma, браузерные и собственные серверы.
