В JavaScript восемь типов данных: семь примитивов и объекты. Динамическая типизация и неявное приведение — источник большинства «странных» вопросов на собеседовании вроде `[] + {}`. Если понять несколько правил, эти вопросы перестают быть странными.

## Восемь типов

| Тип | Пример | `typeof` |
| --- | --- | --- |
| `undefined` | `undefined` | `'undefined'` |
| `null` | `null` | `'object'` (историческая ошибка) |
| `boolean` | `true` | `'boolean'` |
| `number` | `42`, `NaN`, `Infinity` | `'number'` |
| `bigint` | `10n` | `'bigint'` |
| `string` | `'текст'` | `'string'` |
| `symbol` | `Symbol('id')` | `'symbol'` |
| `object` | `{}`, `[]`, `new Date()`, функции | `'object'` / `'function'` |

**Примитивы** неизменяемы и передаются по значению. **Объекты** передаются по ссылке: две переменные могут указывать на один и тот же объект.

```js
let a = 'hello';
let b = a;
b += '!';
a; // 'hello' — примитив скопирован

const user = { name: 'Анна' };
const admin = user;
admin.name = 'Ольга';
user.name; // 'Ольга' — одна и та же ссылка
```

> [!NOTE]
> Функция — тоже объект (у неё есть свойства `name`, `length`, можно добавлять свои), но `typeof` для неё возвращает `'function'`. Массив — объект, поэтому для проверки используйте `Array.isArray(value)`.

## Как надёжно проверять тип

```js
typeof null; // 'object' — поэтому null проверяют отдельно
value === null;

Array.isArray([]); // true
value instanceof Date; // true, если value создан конструктором Date из этого же realm

Object.prototype.toString.call(new Map()); // '[object Map]'
Number.isNaN(NaN); // true (в отличие от глобального isNaN, не приводит аргумент)
```

## Числа: подводные камни

Все числа (кроме `bigint`) — 64-битные числа с плавающей точкой (IEEE 754).

```js
0.1 + 0.2; // 0.30000000000000004
0.1 + 0.2 === 0.3; // false
Math.abs(0.1 + 0.2 - 0.3) < Number.EPSILON; // true

Number.MAX_SAFE_INTEGER; // 9007199254740991
9007199254740992 === 9007199254740993; // true — точность потеряна
9007199254740992n + 1n; // 9007199254740993n — bigint точен

NaN === NaN; // false — единственное значение, не равное самому себе
Object.is(NaN, NaN); // true
Object.is(0, -0); // false, хотя 0 === -0
```

> [!TIP]
> Деньги храните в минимальных единицах (копейках) целыми числами или используйте библиотеки для десятичной арифметики. Никогда не сравнивайте дроби через `===`.

## Truthy и falsy

В логическом контексте (`if`, `&&`, `||`, `!`) любое значение приводится к `boolean`. Ложных значений ровно восемь, запомните их:

```js
false, 0, -0, 0n, '', null, undefined, NaN
```

Всё остальное — истинно, включая `'0'`, `'false'`, `[]`, `{}` и `new Boolean(false)`.

```js
if ([]) console.log('пустой массив — истина');
if ('0') console.log('строка "0" — истина');
```

## Операторы `||`, `&&` и `??`

`||` и `&&` возвращают **один из операндов**, а не `boolean`:

```js
'' || 'по умолчанию'; // 'по умолчанию'
0 || 10; // 10 — часто это ошибка!
0 ?? 10; // 0 — ?? реагирует только на null и undefined

user && user.name; // короткое замыкание
user?.name; // современная альтернатива
```

> [!WARNING]
> `count || 10` заменит легальный `0` на `10`. Для значений по умолчанию используйте `??`: `count ?? 10`.

## Нестрогое равенство `==`

Алгоритм `==` (Abstract Equality) пытается привести операнды к общему типу:

1. `null == undefined` — `true`, и больше ни с чем они нестрого не равны.
2. Если один операнд число, а другой строка — строка приводится к числу.
3. `boolean` сначала приводится к числу (`true → 1`, `false → 0`).
4. Объект приводится к примитиву через `valueOf()` / `toString()` (точнее, через `Symbol.toPrimitive`).

```js
'1' == 1; // true
true == 1; // true
'' == 0; // true
'0' == false; // true: false → 0, '0' → 0
null == 0; // false — null равен только undefined
[] == false; // true: [] → '' → 0, false → 0
[1] == 1; // true: [1] → '1' → 1
```

Строгое равенство `===` сравнивает без приведения: разные типы — всегда `false`.

> [!INTERVIEW]
> «Когда допустимо `==`?» — Единственный распространённый идиоматический случай: `value == null`, что проверяет сразу `null` и `undefined`. Во всех остальных случаях используйте `===`. ESLint-правило `eqeqeq` с опцией `{ null: 'ignore' }` разрешает ровно это.

## Приведение объектов к примитиву

Когда объект участвует в `+`, сравнении или шаблонной строке, вызывается `Symbol.toPrimitive(hint)`, а если его нет — `valueOf()` и `toString()` в порядке, зависящем от подсказки (`'number'`, `'string'` или `'default'`).

```js
const price = {
  amount: 100,
  [Symbol.toPrimitive](hint) {
    return hint === 'string' ? `${this.amount} ₽` : this.amount;
  },
};

`${price}`; // '100 ₽'
price * 2; // 200
price + 1; // 101 (hint 'default' → число)
```

Отсюда знаменитые примеры:

```js
[] + []; // '' — оба массива → ''
[] + {}; // '[object Object]'
1 + '2'; // '12' — если хотя бы один операнд строка, + склеивает
'3' * '4'; // 12 — остальные арифметические операторы приводят к числу
+'42'; // 42 — унарный плюс
+'42px'; // NaN
parseInt('42px', 10); // 42
```

## Явное приведение

Предпочитайте явные функции — код читается без знания таблиц приведения:

```js
String(123); // '123'
Number('  42  '); // 42 (пробелы обрезаются)
Number(''); // 0 — осторожно
Number(null); // 0
Number(undefined); // NaN
Boolean('false'); // true
```

## Коротко

- Семь примитивов + объекты; примитивы копируются, объекты передаются по ссылке.
- `typeof null === 'object'`, для массивов — `Array.isArray`, для NaN — `Number.isNaN`.
- Восемь falsy-значений; `[]` и `'0'` — истинны.
- `??` вместо `||` для значений по умолчанию.
- `===` везде, кроме идиомы `value == null`.
